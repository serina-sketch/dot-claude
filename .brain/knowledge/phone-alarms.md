# Making my phone ring from Claude (research)
*Checked 2026-10-25, for the plan [phone-reminders-app.md](../plans/phone-reminders-app.md). My phone: Motorola Razr 2025 (Android).*

- **The Claude Android app** can set real alarms and timers in the phone's Clock app, on every plan and in voice mode. It can't make reminders on Android (those are iPhone only). A Claude Code cloud session can't do this, because it runs on a remote computer, not on the phone. Source: [Claude Help Center](https://support.claude.com/en/articles/11869629-using-claude-with-android-apps).
- **ntfy** (free app and server): since Android app v1.16, each topic can be set to "Keep alerting on highest priority" and to override Do Not Disturb. A message sent at max priority then replays its sound until you dismiss it. It works like a loud repeating notification, not a full-screen alarm. Messages can be scheduled to arrive later, so the chat doesn't need to stay open. Sources: [ntfy-android releases](https://github.com/binwiederhier/ntfy-android/releases), [the maintainer's post](https://lemmy.linuxuserspace.show/comment/427).
- **MacroDroid** has its own webhook server, so a web request can start a macro, and the webhook can pass values like the time. It also seems to have a "set alarm clock" action. Nobody documents chaining the two, so it's unconfirmed. Source: [MacroDroid forum](https://www.tapatalk.com/groups/macrodroid/viewtopic.php?p=2744).
- **Tasker** can notice when an alarm changes and send it out, but I found no ready-made way to set, list and delete alarms from outside the phone. Source: [notenoughtech](https://notenoughtech.com/tasker/how-to-sync-android-alarm-with-nodered/).
- **Android itself:** other apps can *create* an alarm in the Clock app, but they can't list or delete its alarms. So with any of these tools, the list of alarms Claude manages has to live somewhere outside the Clock app. No existing alarm app has a full web API to create, list and delete alarms (Sleep as Android only sends events out). Source: [Android AlarmClock reference](https://developer.android.com/reference/android/provider/AlarmClock.html).
