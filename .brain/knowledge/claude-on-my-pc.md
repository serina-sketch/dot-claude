# Using Claude on my PC
*Ways to run Claude so it can use the programs on my computer, researched 2026-11-09.*

## What I found (2026-11-09)
Why: I already have the Claude desktop app, but it seemed it couldn't run programs on my computer (like the nudge window or the Proton Mail Bridge script), so I asked how people use Claude on their own computers.

- **The desktop app's Code tab** is Claude Code. When starting a session you choose where it runs: **Local** (my machine, a folder on my PC), **Remote** (Anthropic's cloud) or SSH. Only a Local session can run my scripts. A cloud session, or Cowork, can't, which is probably what I ran into. It has a built-in terminal, and `claude --desktop` (or `/desktop` in a terminal session) moves a session into the app. One guide says the Code tab on Windows needs Git for Windows installed. Source: [Desktop application docs](https://code.claude.com/docs/en/desktop), [setup docs](https://code.claude.com/docs/en/setup).
- **Computer use** (beta, Pro/Max): Claude clicks, types and opens apps on my screen, in Cowork and in Claude Code in the desktop app, on Windows and macOS. Turned on in Settings > Capabilities (or Settings > System, under This computer), with "Full control". The computer must be awake and the app open. There's no sandbox between Claude and my apps. Source: [Let Claude use your computer in Cowork](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork).
- **Cowork** runs sessions in the cloud and reaches my computer through the desktop app when it needs local files or the browser. Its scheduled tasks run in the cloud. Source: [Get started with Claude Cowork](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork).
- **Dispatch**: message Claude from my phone and have it work on my desktop with my local files, connectors and apps. Source: [Assign tasks from anywhere in Claude Cowork](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork).
- **How people run a personal assistant with Claude Code:** a folder of markdown files (often an Obsidian vault) plus slash commands for routines like `/morning` and `/evening`, and a daily note Claude keeps. That's close to what I already have. Sources: [Ron Forbes, RonOS](https://www.ronforbes.com/blog/build-your-personal-ai-assistant-with-claude-code), [Michael Crist](https://michaelcrist.substack.com/p/personal-ai-assistant), [Hannah Stulberg](https://hannahstulberg.substack.com/i/184061644/why-does-claude-code-use-markdown).
