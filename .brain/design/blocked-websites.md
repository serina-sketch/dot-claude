# Websites that block Claude

*Decided 2026-11-09, in claude-assistant.*

When a site refuses Claude's plain download because it looks like a bot, Claude opens it in my own Chrome (Claude in Chrome) instead, without asking. Why: Reddit refused the download of a post I wanted to read, and a second plain try was stopped as dodging the bot check, so Chrome is the honest way in, the same as me clicking the link.

Known so far (2026-11-09): Reddit is also on Claude in Chrome's list of blocked sites, so for Reddit the fallback is me pasting the text.
