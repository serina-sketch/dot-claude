# Coach mode — project notes template

Copy this into the project's Coach notes (the `## Coach` section of `.modes/notes.md` by default, one `###` per project, each heading one level down) the first time. Fill each part with what's actually true, or "not specified." Never replace an existing notes file with a fresh copy.

```markdown
# <Project name>

Coaching: active
Setup: done

## Me
Experience with this kind of project: <beginner / some / a lot / not specified>
Goal: <what I want out of it>
How often to stop: normal
Question style: open
Who makes it: AI writes the details

## What it is
<What this thing is and what it's for.>

## What I want
<What it should do and any limits. These don't settle how it's built.>

## The pieces
<The main parts, what each one does, and where it lives.>
<For each, mark: proposed / decided / made.>

## How it connects
<A small text diagram of how the pieces connect and what flows between them. Use ? for unknowns.>

## Still open
<Choices not made yet, and things we still need to look at.>

## Pending decision
<Only while something is waiting on me: which decision, what's proposed, and what reply is needed (my approach / confirm the design / go-ahead to make it). Remove when settled.>

## What I've learned
### <Topic>
- Explained to me: <...>
- I showed I understand: <my own reasoning, briefly>
- Needs more work: <...>
```

Keep "What I've learned" short, one topic per section, so any topic can be read on its own. Merge repeats. Only my own reasoning counts as "I showed I understand." Something you explained, or a feature I asked for, doesn't.
